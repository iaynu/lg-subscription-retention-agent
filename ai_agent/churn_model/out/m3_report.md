# M3 SHAP 유형 산출 리포트

> 가설 기반 synthetic data. 정답 유형은 생성 때 심은 값이라 '복원율'은 심어 둔 규칙을 다시 찾은 정도입니다(순환 검증). 파이프라인이 동작함을 확인하는 결과로만 읽어 주세요.

- 방법: XGBoost 내장 TreeSHAP → 유형 그룹별 순합 → 양수 그룹만 → 비중 ≥ 20% 그리고 그룹 SHAP ≥ 0.5(로그오즈), 최대 3개
- 가법성 확인: SHAP 합 + 기준값 = 예측 마진, 최대 오차 2.6e-06
