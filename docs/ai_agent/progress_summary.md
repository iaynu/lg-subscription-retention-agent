## 2. 데이터·모델 결과(1~2단계)

- 전체 이탈 8.3%, 정상군 1.1%, 유형 활성군 37%.
- 모델: 시험 6,000건 PR-AUC 0.545(이탈률의 약 6.5배), ROC-AUC 0.908, Recall@10% 0.647. 5-겹 교차 적합 OOF PR-AUC 0.573, HIGH 이탈률 54.3%(이탈자의 65.4% 포착).
- SHAP 유형(비중 20% + 그룹 SHAP 0.5): 위험 상위 20%에서 정답 유형 하나라도 맞힘 99.9%, 주 유형 1순위 일치 78.8%. 약점: T04 재현율 약 24~32%, T08 49%.
- 시연 12건(D01~D12)은 모의 LLM으로 12/12 의도한 결과. 통과율은 정확도가 아님.

## 3. OpenAI 실측(Agent, 2026-10-08)

- 도구: `scripts/measure_llm.py` + `data/demo_inputs_12.json`(사용자 PC 실행, DB 불필요). 키는 환경변수 `OPENAI_API_KEY`로만 읽음. usable = pass + retry_pass.
- 프롬프트 A/B(nano, usable): v3.2 85% / v3.3 77% / **v3.4 90%(기본값)**. v3.3·v3.5는 폐기.
- **현재 기준선 = nano + v3.4 + 후보별 힌트(HINT_GUARD)**: 1차 통과 84%, usable 95.5%, 일부 템플릿 4.5%, 전체 템플릿 0%. 남은 실패(재시도 유발): E2 10·E3 10·M4 9·M8 7·M7 5.
- mini(v3.4, n=100): usable 89%, 1차 통과 55%. 현재는 nano 유지.
- 카탈로그: `S-T04-D`·`S-T07-C` 비활성, 선택 가능 솔루션 33개. `S-T09-C` 구분을 정보제공으로 변경 [제안, 팀 확인 필요].
- 후보별 힌트 채택·E2 허용 범위·M3 처리 등은 [팀 결정 필요] (§6).

## 4. 설문 시뮬레이터·후보 에이전트·승인 흐름(4~6단계)

- 설문 데이터(시드 42): 9,000건 발송 / 응답 1,843건. 저장은 long 형식(`survey_send / survey_response / survey_answer / synth_truth_topic`). 숨은 주제 H-A(가입 시 설명·서비스 범위 불일치)·H-B(케어 가치 불신·자가관리 대체)는 후보 생성에는 쓰지 않고 사후 회수 검증에만 씀.
- 후보 에이전트(`feedback/candidates.py`): 근거 묶음 → 1단계 분류(기존 유형과 정확히 일치하는 문장 제외) → LLM → 검증기(근거 건수·인용문은 코드가 계산, 잘못된 셀만 제거) → 폴백 → `ai_proposal`(상태 '검토중'). 기본은 **3회 실행해 과반(2회 이상)에서 반복된 후보만 남기는 합의 방식**(`--runs 3`), `min_support` 기본 8.
- 합의 3세트 결과(mini, 2단계): H-A 대응 후보 3/3회 매번·정밀도 40~46%(기준선 5.0%)·재현율 12~13%, H-B 대응 후보 3/3회 매번·정밀도 14~24%(기준선 4.3%)·재현율 6~13%. 재현율은 문장 작성자 수(각 약 20명)로 구조상 상한이 낮음. [확정: 순환 검증 기준]
- 합의는 실행마다 흔들리는 후보는 거르지만 "기존 유형 재서술"은 못 거름. 세트 간 반복되는 숨은 주제 외 후보("일정·안내 지연형", "이전·해지 절차 혼선형" 등)는 T06·T02·T03 재서술 가능성이 높아 관리자가 `closest_type_id`·`difference`를 보고 판단. [가정]
- 승인 흐름(`feedback/approve.py`): 채택 시 새 유형 ID(T11~)와 솔루션 행을 비활성(`active_yn='N'`, `agent_selectable_yn='N'`)으로 추가, 기각은 상태만 변경(사유 필수), 활성화는 별도 단계. 새 유형은 모델이 모르므로 재학습·매핑 전에는 Agent가 쓰지 않음.
- 가격(공식 모델 페이지 2026-10-10 확인, 100만 토큰당): gpt-5.4-mini 입력 $0.75 / 출력 $4.50, gpt-5.4-nano $0.20 / $1.25(nano는 deprecated 표시). 합의 1회 실행(mini) 약 $0.13~0.14(약 190원, 환율 1,400원 가정).
- 테스트: 전체 490 passed(PostgreSQL 포함). 상세 설계·결과는 `docs/survey_simulator_design.md` §9~§12.

## 7. 알려진 한계

- 합성 정답 기준 순환 검증이며 정확도가 아님.
- 후보 에이전트 결과는 합의 3세트(각 내부 3회)만 확인. 1단계 분류는 실행마다 흔들리나 합의가 흡수함. H-B는 항상 찾지만 정밀도 편차가 큼.
- no_type 코호트가 매우 작음(약 91건/응답 약 17건)이라 숨은 주제 근거는 주로 post_action·post_churn 코호트에 있음.
